# Project Abstract - Personal Portfolio Website

## Problem statement
Students graduating from the MCA programme have no single, verifiable place
to show the work they produced during the semester.

## Objectives
1. Build a responsive portfolio with semantic HTML5 and CSS3.
2. Present at least three projects with screenshots and repository links.
3. Validate the contact form on the client side.
4. Deploy on GitHub Pages.

## Approach
Work is delivered in four sprints, each one recorded as a commit range in
this repository so faculty can review the diff on GitHub.
